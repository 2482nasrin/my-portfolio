# My Portfolio Project

A responsive personal portfolio website created with Next.js (App Router) & Tailwind CSS based on the Inbio design.

## Project Structure
- `app/` - Page router components and styles
- `public/images/` - Profile images and project assets
- `public/images/icons/` - SVG icons (Figma, Sketch, LinkedIn, etc.)

## How to Run

1. Clone or extract the project.
2. Install dependencies:
